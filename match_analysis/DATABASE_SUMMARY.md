## Database Tables

| Table | Description |

| `processing_log` | Processing run history |

### `maps` table classification columns

| Column | Type | Description |
|--------|------|-------------|
| `wools_per_team` | INTEGER | Wool objectives per team (rounded avg); 0 = non-CTW map |
| `max_players_per_team` | INTEGER | Max players per team (rounded avg across teams) |
| `total_blocks` | INTEGER | Buildable surface block count from `layout_top_surface.parquet` (block ID 36 excluded) |
| `size_tier` | VARCHAR | Server tier label (`pico`/`nano`/`micro`/`milli`/`centi`/`hecto`/`mega`/`giga`) |
| `symmetry_type` | VARCHAR | Primary global symmetry from `symmetry.json` (`rot_180`, `mirror_x`, `mirror_z`, `rot_90`, `none`) |
| `has_intra_team_symmetry` | BOOLEAN | Whether any team's island cluster has intra-team symmetry detected |

### `map_size_buckets` view

A derived view over `maps` that assigns each map to one of five area buckets using NTILE(5) percentile ranking on `total_blocks`. Query it like a table:

```sql
SELECT map_slug, map_size_bucket FROM map_size_buckets WHERE map_size_bucket = 'huge';
```
